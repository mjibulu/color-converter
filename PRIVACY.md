# Privacy

Color Picker & Converter processes tool input locally in the browser.

This application:

- Does not include analytics, advertising, or telemetry.
- Does not upload tool input or output.
- Does not require an account.
- Tests primary workflows for unexpected external requests.

## Browser storage

This tool may store the following tool-specific keys locally: `color-converter:saved-colors:v1`.

## Browser capabilities

This tool uses: Clipboard API, EyeDropper API, Blob downloads. Availability may vary by browser.

Deployments may be modified by their operators. Review the source and the
deployed site's policies before using a build from an unfamiliar source.
